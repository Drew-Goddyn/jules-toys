Signal Path Lab: Blackout Protocol

Blackout Protocol

  1. Click a source (top) and target (bottom) are color-coded pairs
  2. Click empty cells to place wires — route a path from each source to its target
  3. Each action costs energy. Budget is tight.
  4. Fault cells spread each turn, breaking wires they cover
  5. Click a fault to repair it (costs extra energy)
  6. Connect all pairs before energy runs out
